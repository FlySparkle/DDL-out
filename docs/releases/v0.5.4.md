# DDL out! v0.5.4

## 更新内容

- 新事项的剩余时间默认 0 天 0 时 0 分，绝对时间默认当前本地时间。剩余时间预设
  为累加的 `+1d`、`+1h`、`+15m`；绝对时间预设为今天、明天、本周末。支持添加、
  删除自定义预设和鼠标滚轮横向浏览。
- 事项详情支持 Markdown 与 LaTeX 公式预览、全屏阅读，以及从标题生成的可跳转大纲。
- 新增系统闹钟导出及多重闹钟。Windows 使用任务计划程序，到点启动独立且与应用
  主题一致的闹钟窗口，主程序关闭后仍可弹窗；修复关闭闹钟时的原生窗口析构崩溃。
- Android 使用系统时钟接口直接提交，请求跳过确认界面；闹钟浮窗与事项编辑器同宽，
  适配手机、平板及键盘弹出。
- 设置首页在“外观与个性化”上方增加“闹钟管理”，管理页提供列表操作和一键清空。
  Windows 删除本应用创建的闹钟；Android 清空本应用导出记录，实际闹钟在系统时钟管理。

## 闹钟说明

Windows 电脑必须开机且用户已登录。锁屏时需解锁查看，睡眠唤醒取决于设备和系统
电源设置；关机时不能弹窗。请保留程序目录，移动或删除该目录后需重新添加闹钟。

Android 官方接口不能指定任意年月日：下一次时刻使用一次性闹钟，其余未来日期
按对应星期设置每周重复，可能在事项日期之前响铃。系统时钟没有标准创建成功回执；
个别时钟应用可能忽略跳过界面的请求。事项后续修改、完成或删除不会自动同步闹钟。

## 下载与升级

请在 GitHub Release 选择对应系统及 CPU 架构的安装包，使用 `SHA256SUMS.txt` 校验下载。
Windows 便携 ZIP 需要完整解压，保留其中的 DLL 和 `data` 文件夹。

Android 正式包采用项目既有发布密钥。若安装了此前的本地调试签名 APK，请先导出
备份；不同签名的 APK 不能直接覆盖安装，必要时卸载调试版、安装正式版后恢复备份。

## 验证

141 项 Flutter 回归测试、静态分析和 Android release 构建通过。Windows Task Scheduler
真实集成验证覆盖未来日期登记、列表、停用、删除、独立弹窗及关闭后退出码 0。
Android 同宽布局已验证手机、平板及键盘避让；当前未连接 Android 真机，厂商时钟
免确认行为尚未在真机验证。正式发布还需通过 GitHub CI 和多平台 release 构建。
