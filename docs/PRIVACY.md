# 隐私政策

最后更新：2026-08-12

DDL out!（以下简称"本应用"）是一款本地优先的桌面与移动端应用。

## 数据收集

**本应用不收集、不上传、不分享任何个人数据。**

- 所有事项、分类、截止时间和完成状态均存储在您的设备本地 SQLite 数据库中。
- 本应用不接入任何分析、广告或遥测服务。
- 仅当您主动使用“附近同步”时，本应用才会访问本地网络，与您扫描二维码配对的
  设备直接交换数据；同步内容不会发送至互联网服务器。
- 移动端仅在您打开扫码页面时请求相机权限，相机画面只用于在设备上识别同步
  二维码，不会被保存或上传。
- 启动时自动检查更新默认开启，您可以在“系统与数据”中关闭。检查更新会请求
  GitHub Releases API，但不会包含事项或备份数据。
- 您可以选择保存 GitHub Token 以减少匿名 API 请求的频率限制。Token 保存在
  本机应用偏好设置中，不会进入事项数据库或 JSON 备份；检查更新时会作为 HTTPS
  `Authorization` 请求头发送给 GitHub，并可随时清除。

## 备份与导出

备份功能将数据导出为本地 JSON 文件，由您自行选择存储位置。本应用不会自动上传
备份文件至任何远程服务。

## 第三方服务

本应用不接入云同步、分析、广告或遥测服务。二维码识别与加密由应用内依赖库在
设备本地完成。更新检查与外部链接会访问 GitHub，相关处理受 GitHub 隐私声明与
服务条款约束。

## 儿童隐私

本应用不收集任何人的数据，儿童同样适用。

## 变更

本隐私政策如有更新，将通过应用更新渠道同步通知。
