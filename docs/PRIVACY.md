# 隐私政策

最后更新：2026-07-22

DDL out!（以下简称"本应用"）是一款本地优先的桌面与移动端应用。

## 数据收集

**本应用不收集、不上传、不分享任何个人数据。**

- 所有事项、分类、截止时间和完成状态均存储在您的设备本地 SQLite 数据库中。
- 本应用不接入任何分析、广告或遥测服务。
- 仅当您主动使用“附近同步”时，本应用才会访问本地网络，与您扫描二维码配对的
  设备直接交换数据；同步内容不会发送至互联网服务器。
- 移动端仅在您打开扫码页面时请求相机权限，相机画面只用于在设备上识别同步
  二维码，不会被保存或上传。

## 备份与导出

备份功能将数据导出为本地 JSON 文件，由您自行选择存储位置。本应用不会自动上传
备份文件至任何远程服务。

## 第三方服务

本应用不接入云同步、分析、广告或遥测服务。二维码识别与加密由应用内依赖库在
设备本地完成，不会把数据交给第三方服务。

## 儿童隐私

本应用不收集任何人的数据，儿童同样适用。

## 变更

本隐私政策如有更新，将通过应用更新渠道同步通知。
