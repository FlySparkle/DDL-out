# ADR 003: 事项详情与内联图片

- 状态：已采纳
- 日期：2026-07-27

## 背景

事项需要在标题之外保存详情文字，并允许直接粘贴来自文件管理器或系统图片剪贴板的图片。详情必须离线可用，也必须随整库备份和局域网同步迁移，不能依赖原始图片路径长期存在。

## 决定

- `tasks` 表新增 `details` 与 `detail_images_json` 字段，数据库架构版本升至 4。
- 图片以带 UUID、MIME 类型和 Base64 数据的版本内 JSON 记录保存在事项行中。
- 单个事项最多保存 12 张图片；单张原始数据不超过 10 MiB；合计不超过 30 MiB。
- JSON 备份架构升至 3；旧备份恢复时为新增字段补空值。
- 局域网同步协议升至 2，并把详情文字与详情图片作为两个独立字段参与合并和冲突处理。
- Windows、Linux 和 macOS 优先读取剪贴板中的图片文件；没有图片文件时再读取系统位图。读取后立即复制字节到数据库，不保存外部路径。

## 影响

内联存储让离线访问、整库备份和点对点同步保持一致，但图片会增大数据库、备份和同步消息体积，因此必须执行数量与大小限制。同步协议版本不同的设备不能建立会话，避免旧客户端静默丢弃详情字段。
