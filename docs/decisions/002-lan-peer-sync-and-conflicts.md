# ADR 002：局域网点对点同步与字段级冲突

## 状态

于 2026-07-22 采纳。

## 背景

手机和电脑可能在离线期间各自修改同一份数据。整库覆盖会丢失其中一端的改动，
仅依赖更新时间也无法判断两个修改是否具有因果关系。

## 决策

- 电脑生成两分钟有效的一次性二维码，手机在同一局域网内通过 WebSocket 直连。
- 二维码携带随机 256 位会话密钥，所有同步消息使用 AES-GCM 加密，不经过云端。
- 每个实体使用跨设备 UUID，每次修改记录不可变操作及版本向量。
- 两端先交换版本向量，只发送对方缺少的操作；不同字段自动合并。
- 同一字段的并发不同值保留为候选项并建立冲突，不静默覆盖。
- 删除使用墓碑并在并发时暂时优先，避免已删除内容意外复活。
- 生成二维码的电脑默认负责冲突审批；用户可明确切换到手机审批。审批本身也是
  可同步的操作，因此另一端离线时不会丢失决定。

## 影响

数据库保留本地整数主键以兼容现有界面，同时增加同步 UUID、操作日志、字段头、
设备确认向量和冲突表。整库备份恢复前必须先移除已配对设备，防止同步历史与恢复
后的数据身份不一致。
