# ADR 006：可选事项截止时间

## 状态

于 2026-08-12 采纳。

## 背景

部分事项需要保留在看板中，但没有适合填写的截止时间。用一个很远的日期模拟
“不限时”会制造错误倒计时，也会污染排序、备份和跨设备同步语义。

## 决策

- 事项的 `deadlineUtc` 改为可空字段；`null` 明确表示“不限时”。已有事项及旧版
  备份继续保留原截止时间。
- 编辑器提供“不限时”快捷项和输入模式。不限时事项不显示倒计时或紧迫度进度，
  显式按截止时间排序时排在同一完成状态内的有时限事项之后。
- JSON 备份格式提升到版本 6，并允许 `deadlineUtc` 为 `null`；1 至 5 版备份仍按
  原规则读取。
- 局域网同步操作允许截止时间候选值为 `null`。由于旧客户端不能解释该值，同步
  协议提升到 6，配对密钥使用 `DDL6:` 前缀，不与协议 5 会话互通。

## 影响

数据库升级会重建事项表以放宽截止时间约束，不改写已有值。所有事项创建、编辑、
排序、备份、恢复、同步、冲突显示和卡片展示都必须保留 `null` 语义，禁止重新引入
超远日期哨兵值。
